### a. Dataset download

Due to the size of this datase (4.82 GiB), we decided to create a script called **downloader.py** to download the dataset from Kaggle. In order for this script to run, you should have your Kaggle tokens ready. This can be done by doing the following:

1. Log in to your Kaggle account and head to Settings
2. Scroll down to API Tokens and click on "Create new token"
3. Copy that token and paste in when prompted "Enter your Kaggle token"

```bash
python downloader.py
```
